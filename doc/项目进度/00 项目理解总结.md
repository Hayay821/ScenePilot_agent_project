## 今晚实现方案（01算法验证）

### 技术栈
- **Python**: 3.11
- **核心框架**: FastAPI, Pydantic, asyncio
- **视频处理**: OpenCV, PyAV, FFmpeg
- **本地视觉**: Ultralytics YOLO, ByteTrack (可选), MediaPipe
- **百炼API**: OpenAI SDK (兼容端点)
- **数据**: SQLite + JSONL
- **UI**: Streamlit (快速验证)

### 实现步骤（按Task顺序）

#### **Task 1: 项目骨架与Schema** (15分钟)
创建目录结构，定义Pydantic数据模型：
- `FramePacket`: 帧数据包
- `SelectedFrame`: STC选中的关键帧
- `VideoEvent`: 语义事件
- `CameraAction`: 设备命令
- `RunMetrics`: 运行指标

#### **Task 2: 流式视频输入** (20分钟)
实现`FileVideoSource`类：
- 使用OpenCV读取本地MP4
- 支持`realtime=False`快速模式和`realtime=True`模拟实时模式
- 实现10秒`RingBuffer`环形缓冲区
- 输出单调递增时间戳的`FramePacket`

#### **Task 3: STC启发式压缩** (30分钟)
实现`HeuristicSTC`类：
- 计算帧差（灰度差、HSV直方图、感知哈希）
- 基于变化分数和时间间隔选择关键帧
- 输出选择原因和压缩率
- 支持配置化阈值

#### **Task 4: 语义Provider** (30分钟)
实现两个Provider：
- `MockSemanticProvider`: 返回模拟事件（无需API Key）
- `DashScopeVLSemanticProvider`: 
  - 通过OpenAI SDK调用百炼兼容端点
  - 批量发送2-4张关键帧
  - 要求JSON输出并Pydantic校验
  - 超时、重试、缓存机制

#### **Task 5: 导演状态机** (25分钟)
实现`DirectorStateMachine`纯函数式状态机：
- 状态：IDLE → SEARCH → TRACK → RECORD → HIGHLIGHT → RECOVER
- 根据`VideoEvent`生成受约束的`CameraAction`
- 使用Mock设备适配器记录命令（不执行）

#### **Task 6: 端到端CLI** (20分钟)
实现命令行接口：
```bash
python -m app.cli analyze \
  --input data/input/demo.mp4 \
  --intent "跟拍骑马的人，记录动作高潮" \
  --mock  # 使用Mock模式
```

输出：
- `keyframes/`: 关键帧图片
- `events.jsonl`: 事件时间线
- `commands.jsonl`: 设备命令
- `metrics.json`: 运行指标
- `highlights.mp4`: 高光片段

## 明天硬件接入方案（02硬件平台）

### 架构设计

```
Python AI Service (FastAPI)
  |
  ├─> x4air-bridge (C++ localhost:8001)
  │     ├─ Camera SDK: USB控制、预览、录制
  │     ├─ Media SDK: .insv拼接、equirectangular导出
  │     └─ OSC fallback: Wi-Fi HTTP备选
  |
  └─> link2-bridge (C++ localhost:8002)
        ├─ UVC capture: 视频流读取
        ├─ UVCCameraController: PTZ/曝光/对焦
        └─ UVCCameraExtendController: 追踪/构图/手势
```

### 统一设备协议

#### 能力查询
```
GET /v1/capabilities
→ {device_id, device_type, capabilities: {...}}
```

#### 命令提交
```
POST /v1/commands
{command_id, action, args, deadline_ms}
→ {status, result, error}
```

#### 状态事件流
```
WebSocket /v1/events
→ 连接状态、录制状态、温度警告、文件生成
```

### 实现任务

#### Task A: Link 2 C++ Bridge
基于官方Link-SDK创建最小服务：
- 设备枚举和能力查询
- Pan/Tilt绝对位置控制
- 视频模式、构图、追踪目标设置
- 安全保护：范围检查、超时、Stop命令

#### Task B: X4 Air Camera Bridge
基于Desktop Camera SDK：
- USB设备发现和连接
- 开始/停止录像
- 预览流
- 文件列表和下载（X4 Air支持）
- OSC fallback备选

#### Task C: X4 Air Media Worker
基于Desktop Media SDK：
- `.insv` → `equirectangular.mp4`离线拼接
- 任务队列、进度、日志
- GPU检查（3.x版本要求）

#### Task D: Python Adapter
- `Link2DeviceAdapter`和`X4AirDeviceAdapter`
- 统一`CameraAction`接口
- 能力缓存、超时、熔断、Mock fallback

#### Task E: Edge/Cloud分工
- Edge Agent: 本地检测跟踪、PTZ闭环、关键帧上传
- Cloud Service: 语义分析、事件管理、Web UI
- 断网resilience: 本地outbox队列

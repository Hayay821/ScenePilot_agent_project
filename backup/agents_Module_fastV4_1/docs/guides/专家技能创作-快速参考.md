# 专家技能创作功能 - 快速参考

## 一句话描述

专业摄影师用自然语言描述经验 → SkillsManager 自动提取为结构化技能 → 保存到技能库

---

## 快速开始

```bash
python test_agents.py skills-author \
  --mode bailian \
  --expert-input "你的摄影经验描述"
```

---

## 核心流程

```
1. 输入专家经验（自然语言）
   ↓
2. LLM 自动提取结构化技能
   ↓
3. 展示提取结果（中文）
   ↓
4. 用户选择保存位置
   - personal（个性化库）
   - builtin（内置库）
   - cancel（取消）
   ↓
5. 智能检测相似技能
   ↓
6. 用户选择合并或新建
   ↓
7. 保存并更新索引
```

---

## 示例输入

### 示例 1：人像拍摄

```
"拍摄人像时，我喜欢在黄金时刻拍摄，光线柔和，画面温暖。
我会让模特面向光源，确保眼睛有眼神光。
构图时会留出视线方向的空间，让画面更有呼吸感。"
```

**系统会提取**：
- 名称: Golden Hour Portrait
- 阶段: director
- 类型: portrait
- 规则: 3 条

### 示例 2：产品摄影

```
"拍摄产品时，我总是使用纯白背景。
我会从多个角度拍摄：正面、侧面、45度角和细节特写。
光源要均匀，避免阴影。"
```

**系统会提取**：
- 名称: Clean Product Photography
- 阶段: director
- 类型: product
- 规则: 3 条

### 示例 3：通用构图

```
"无论拍摄什么题材，我都会注意三分法则。
将主体放在画面的交叉点上，可以创造平衡且有视觉吸引力的画面。"
```

**系统会提取**：
- 名称: Rule of Thirds
- 阶段: common（通用）
- 类型: common（通用）
- 规则: 1-2 条

## 目录结构

```
skills/repository/
├── builtin/          # 内置技能库（团队共享）
│   ├── common/      # 通用技能（所有阶段）
│   ├── director/
│   │   ├── portrait/
│   │   ├── landscape/
│   │   ├── product/
│   │   └── sports/
│   ├── cinematographer/
│   └── editor/
├── personal/        # 个性化技能库（个人风格）
│   ├── common/
│   ├── director/
│   ├── cinematographer/
│   └── editor/
├── pending_review/  # 待审核技能（临时）
└── skill_index.json # 技能索引表（自动维护）
```

---

## 技能分类

### stage（阶段）

| 值 | 说明 |
|---|---|
| `director` | 拍摄前规划 |
| `cinematographer` | 实时拍摄 |
| `editor` | 后期剪辑 |
| `common` | 通用（所有阶段） |

### category（类型）

| 值 | 说明 |
|---|---|
| `portrait` | 人像 |
| `landscape` | 风景 |
| `product` | 产品 |
| `sports` | 运动 |
| `common` | 通用（所有类型） |

---

## 智能合并

系统会自动检测相似的现有技能：
- 相同 stage 和 category
- 相似的名称

**合并策略**：
- 避免重复规则
- 合并所有唯一标签
- 更新时间戳

**用户选择**：
- **合并**：将新规则添加到现有技能（推荐）
- **新建**：创建独立的新技能

## 常见问题

### Q: 提取不准确怎么办？

A: 确保使用 `--mode bailian`（真实 API），不要用 mock 模式。

### Q: 如何查看待审核的技能？

A: 查看 `skills/repository/pending_review/` 目录。

### Q: 如何撤销错误的保存？

A: 删除对应的 YAML 文件，然后重建索引：

```python
from fast import ScenePilotFast
app = ScenePilotFast(mode="bailian")
app.skills._rebuild_index()
```

### Q: 索引表损坏怎么办？

A: 重建索引（同上）。

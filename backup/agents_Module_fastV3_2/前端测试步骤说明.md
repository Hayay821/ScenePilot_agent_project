当前前端只需要把服务启动模式从 `mock` 改成 `bailian`,就可以测试真实环境下的百炼模型，前端本身不需要修改，因为它调用的是同一套 `/api/v1` 接口。

## 1. 确认 `.env`

确认文件存在：

```text
F:\BoldMaker\project00\agents_Module_fast\.env
```

至少包含：

```env
DASHSCOPE_API_KEY=你的百炼API Key
DASHSCOPE_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
DASHSCOPE_MODEL=qwen-vl-plus
```

不要把真实 Key 发给我，也不要放进前端代码。

可以用 PowerShell 检查变量是否已经加载，但不要打印 Key：

```powershell
cd F:\BoldMaker\project00\agents_Module_fast

python -c "from dotenv import load_dotenv; import os; load_dotenv('.env'); print('API_KEY:', bool(os.getenv('DASHSCOPE_API_KEY'))); print('BASE_URL:', os.getenv('DASHSCOPE_BASE_URL')); print('MODEL:', os.getenv('DASHSCOPE_MODEL'))"
```

如果输出：

```text
API_KEY: True
BASE_URL: ...
MODEL: ...
```

说明配置已被读取。

## 5. 直接用 PowerShell 测试真实 Director API

如果前端出现问题，可以直接调用接口：

```powershell
$body = @{
  user_text = '请拍摄一组自然的人像短片，保留人物与环境关系'
  media_input = @{
    source_type = 'FILE'
    paths = @(
      'data/img/img1.jpg',
      'data/img/img2.jpg'
    )
  }
  skills_filter = @{
    stage = 'director'
    limit = 3
  }
  output_config = @{
    output_dir = 'outputs/director'
    save_intermediate = $true
  }
} | ConvertTo-Json -Depth 8

Invoke-RestMethod `
  -Uri 'http://127.0.0.1:8765/api/v1/agents/director' `
  -Method Post `
  -ContentType 'application/json' `
  -Body $body
```

## 7. 判断是否真的使用了百炼

不要只看前端是否返回结果，检查启动服务的终端日志。

应看到类似：

```text
Director Agent - Skills 匹配结果
正在使用视觉模型分析参考图片
Director 分析完成
```

还可以检查：

```json
outputs/director.json
outputs/filming.json
outputs/edit_plan.json
```

如果是 Mock，输出通常会出现：

```text
Mock analysis
```

如果是百炼模式，不应出现 Mock 结果。

启动时也可以检查：

```text
mode=bailian
```

## 8. 常见错误

### API Key 没有加载

错误通常类似：

```text
Bailian mode requires API key
```

检查：

```powershell
python -c "from dotenv import load_dotenv; import os; load_dotenv('.env'); print(bool(os.getenv('DASHSCOPE_API_KEY')))"
```

### 模型不存在

检查：

```env
DASHSCOPE_MODEL=qwen-vl-plus
```

如果账号不支持该模型，替换为百炼控制台中实际可用的视觉模型。

### 401 错误

通常是：

- API Key 错误
- API Key 和 Base URL 地域不一致
- Key 已失效

### 400 错误

可能是：

- 模型不支持当前多模态请求格式
- 图片路径不存在
- 图片格式不支持
- 请求内容过大
- API 输入 JSON 不符合模型要求

### 前端跨域错误

当前服务已经配置 CORS。如果仍然出现跨域错误，可以不要直接双击 HTML，而是启动一个静态文件服务器：

```powershell
cd F:\BoldMaker\project00\agents_Module_fast\frontend
python -m http.server 5500
```

然后打开：

```text
http://127.0.0.1:5500
```

API 服务仍然运行在：

```text
http://127.0.0.1:8765
```

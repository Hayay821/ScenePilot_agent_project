## 1. 概述

### 1.1 项目背景

ScenePilot 是一个**事件驱动的 AI 跟拍导演系统**，通过双设备协同实现智能跟拍：

- **X4 Air 全景相机**: 360° 视角作为"安全网"，全程记录现场
- **Link 2 云台相机**: 实时 PTZ 跟踪，捕捉特写镜头

硬件平台负责将影石官方 SDK（C++）封装为统一接口，供上层 AI 算法（Python）调用。

### 1.2 设计原则

1. **SDK 隔离**: C++ 设备桥独立进程，避免 ABI 冲突和崩溃传播
2. **统一协议**: HTTP/WebSocket 提供一致的能力查询、命令提交、事件流接口
3. **边缘优先**: 本地高频 PTZ 闭环，减少云端延迟
4. **离线韧性**: 本地 outbox 队列，网络恢复后补传
5. **安全第一**: PTZ 范围检查、超时保护、异常退出自动停止

### 1.3 技术栈

| 层级 | 组件 | 技术 |
|------|------|------|
| 硬件层 | X4 Air, Link 2 | USB, UVC |
| 设备桥 | link2_bridge, x4air_bridge | C++17, Link-SDK, Desktop Camera SDK |
| 适配器 | Python Adapters | Python 3.11, httpx, asyncio |
| 边缘代理 | Edge Agent | Python, OpenCV, YOLOv8 |
| 云端服务 | Semantic Analysis | 百炼 API, FastAPI |

### 2.2 数据流

#### 2.2.1 实时跟拍流程

```
1. Link 2 预览流 (30fps)
   └─> Edge Agent: STC 压缩 (3-5fps)
       └─> 本地检测 (YOLO)
           └─> 关键帧上传云端
               └─> 百炼视觉分析
                   └─> 事件生成
                       └─> 导演状态机
                           └─> CameraAction
                               ├─> Link 2: PTZ 控制 (实时)
                               └─> X4 Air: 录制标记
```

#### 2.2.2 素材处理流程

```
1. X4 Air 录制 (全景 .insv)
   └─> 下载到本地
       └─> Media Worker: 拼接处理
           └─> Equirectangular .mp4
               └─> 事件时间线剪辑
                   └─> 高光片段
```

## 3. 核心组件

### 3.1 设备桥 (Device Bridge)

#### 3.1.1 Link 2 Bridge

**职责**:
- 枚举和连接 Link 2 云台设备（USB UVC）
- 提供 HTTP API 用于 PTZ 控制、追踪、构图
- WebSocket 推送设备状态变化

**技术细节**:
```cpp
// 依赖: Link-SDK (官方下载)
#include "UVCCameraSDK.h"
#include "UVCCameraController.h"
#include "UVCCameraExtendController.h"

// HTTP 库: cpp-httplib
// WebSocket 库: websocketpp
// JSON 库: nlohmann/json
```

**编译**:
```bash
cd bridges/link2_bridge
mkdir build && cd build
cmake .. -DLINK_SDK_PATH=/path/to/Link-SDK
cmake --build . --config Release
```

**运行**:
```bash
./link2_bridge --port 8002 --ws-port 8003 --log-level info
```

#### 3.1.2 X4 Air Bridge

**职责**:
- 枚举和连接 X4 Air 全景相机（USB 或 Wi-Fi）
- 提供 HTTP API 用于录制、预览、文件管理
- OSC 协议 fallback（可选）

**技术细节**:
```cpp
// 依赖: Desktop Camera SDK (官方下载)
#include "CameraSDK.h"

// USB 控制: 开始/停止录像、预览流、文件列表/下载
// Wi-Fi fallback: OSC HTTP 协议
```

**编译**:
```bash
cd bridges/x4air_bridge
mkdir build && cd build
cmake .. -DCAMERA_SDK_PATH=/path/to/Desktop-Camera-SDK
cmake --build . --config Release
```

**运行**:
```bash
./x4air_bridge --port 8001 --log-level info
# 可选: --osc-url http://192.168.42.1 (Wi-Fi fallback)
```

#### 3.1.3 Media Worker

**职责**:
- .insv 双鱼眼格式 → Equirectangular .mp4 拼接
- 任务队列管理
- GPU 加速（Media SDK 3.x 要求）

**技术细节**:
```cpp

#include "MediaSDK.h"

// 拼接参数:
// - 投影: EQUIRECTANGULAR
// - 分辨率: 3840x1920 (建议)

```

**编译和运行**:
```bash
cd bridges/media_worker
mkdir build && cd build
cmake .. -DMEDIA_SDK_PATH=/path/to/Desktop-Media-SDK

```

### 3.2 Python 适配器

#### 3.2.1 基类 DeviceAdapter

所有设备适配器继承自 `DeviceAdapter`，提供：

- **能力查询**: `get_capabilities()` 返回设备支持的功能列表
- **命令执行**: `execute_command()` 提交控制命令，返回执行结果
- **连接管理**: `connect()`, `disconnect()`, `is_connected()`
- **容错机制**:
  - 能力缓存（避免重复查询）
  - 超时重试（指数退避）
  - 熔断器（连续失败后自动降级）

**示例**:
```python
from adapters import Link2Adapter

adapter = Link2Adapter(bridge_url="http://localhost:8002")
await adapter.connect()

# 查询能力
caps = await adapter.get_capabilities()
print(f"PTZ 范围: Pan {caps.ptz.pan_range}, Tilt {caps.ptz.tilt_range}")

# 执行命令
result = await adapter.set_pan_tilt(20.0, 5.0)
if result.status == "success":
    print("PTZ 控制成功")
```

#### 3.2.2 Link2Adapter

**特殊方法**:
```python
# PTZ 控制
await adapter.set_pan_tilt(pan_deg=20.0, tilt_deg=5.0)
await adapter.ptz_stop()
await adapter.ptz_home()

# 追踪控制
await adapter.start_tracking(target_id="person_01")
await adapter.stop_tracking()
await adapter.set_track_speed("medium")
await adapter.set_composition_style("half_body")

# 视频模式
await adapter.set_video_mode("standard")
```

#### 3.2.3 X4AirAdapter

**特殊方法**:
```python
# 录制控制
await adapter.start_recording()
await adapter.stop_recording()

# 预览流
await adapter.start_preview()
await adapter.stop_preview()

# 文件管理
files = await adapter.list_files()
await adapter.download_file("/DCIM/video.insv", "./local.insv")
await adapter.delete_file("/DCIM/video.insv")
```

### 3.3 边缘代理 (Edge Agent)

**职责**:
- 管理 Link 2 和 X4 Air 双设备生命周期
- 处理实时帧流和事件队列
- 本地检测跟踪（可选）
- 关键帧上传和云端同步
- Outbox 队列（离线韧性）

**运行**:
```bash
python -m edge.agent \
  --link2-bridge http://localhost:8002 \
  --x4air-bridge http://localhost:8001 \
  --cloud-endpoint https://your-cloud.com \
  --local-mode  # 断网测试模式
```

**内部流程**:
```python
class EdgeAgent:
    async def start(self):
        # 连接设备
        await self.link2_adapter.connect()
        await self.x4air_adapter.connect()
        
        # 启动事件循环
        asyncio.create_task(self._event_loop())
        asyncio.create_task(self._cloud_sync_loop())
    
    async def _event_loop(self):
        while self.running:
            event = await self._event_queue.get()
            # 处理事件...
    
    async def _cloud_sync_loop(self):
        while self.running:
            # 同步关键帧和事件到云端
            await self._sync_batch()
            await asyncio.sleep(1.0)
```

### 4.2 命令提交

#### 请求

```http
POST /v1/commands HTTP/1.1
Host: localhost:8002
Content-Type: application/json

{
  "command_id": "cmd-001",
  "action": "set_pan_tilt_absolute",
  "args": {
    "pan_deg": 20.0,
    "tilt_deg": 5.0
  },
  "deadline_ms": 1000
}
```

#### 响应

```json
{
  "command_id": "cmd-001",
  "status": "success",
  "result": {
    "pan_actual": 20.1,
    "tilt_actual": 5.05,
    "execution_time_ms": 156.3
  },
  "error": null
}
```

#### 命令列表

| 命令 | 参数 | 说明 |
|------|------|------|
| `set_pan_tilt_absolute` | `pan_deg`, `tilt_deg` | 绝对位置控制 |
| `ptz_stop` | - | 停止 PTZ |
| `ptz_home` | - | 归位 |
| `start_tracking` | `target_id` (可选) | 开始追踪 |
| `stop_tracking` | - | 停止追踪 |
| `set_track_speed` | `speed` | 追踪速度 |
| `set_composition_style` | `style` | 构图风格 |
| `start_recording` | - | 开始录像 |
| `stop_recording` | - | 停止录像 |
| `list_files` | - | 列出文件 |
| `download_file` | `file_path`, `local_path` | 下载文件 |

### 4.3 事件流

#### WebSocket 连接



| `recording_stopped` | 录制停止 |
| `file_created` | 文件生成 |
| `error` | 错误事件 |

## 5. 开发指南

### 5.1 前置条件

#### 硬件要求

- X4 Air 全景相机（USB 数据线连接）
- Link 2 云台相机（USB 连接）
- 独立 GPU（Media SDK 拼接需要）

#### 软件要求

- Windows 10+ / Ubuntu 22.04
- Python 3.11
- CMake 3.20+
- C++17 编译器
  - Windows: Visual Studio 2019+
  - Linux: GCC 9+ / Clang 10+

#### SDK 下载

1. **Link-SDK**: https://github.com/Insta360Develop/Link-SDK
2. **Desktop Camera SDK**: 官方开发者网站下载
3. **Desktop Media SDK**: 官方开发者网站下载

### 5.2 第一步: 硬件能力探测

在开始开发前，**必须先验证硬件实际支持的能力**：

```bash
cd hardware_platform

# Link 2 能力探测
python scripts/probe_link2.py
# 输出: data/capabilities/link2_capabilities.json

# X4 Air 能力探测
python scripts/probe_x4air.py
# 输出: data/capabilities/x4air_capabilities.json
```

**关键检查项**:
- Link 2: PTZ 范围、追踪模式、构图风格、手势控制
- X4 Air: 录制格式、预览、文件下载支持（X4 Air 需现场验证）

**注意**: 不要假设文档中的所有功能都被固件支持，以实测为准！

### 5.3 第二步: 编译 C++ 设备桥

#### Link 2 Bridge


## 6. 部署说明

### 6.1 现场边缘部署

#### 硬件配置

```
边缘电脑（现场）:
- CPU: Intel i7 或同等级
- RAM: 16GB+
- GPU: NVIDIA GTX 1660+ (用于 Media SDK)
- 存储: 256GB+ SSD
- 操作系统: Windows 10/11 或 Ubuntu 22.04
- USB 端口: 至少 2 个 USB 3.0
```

#### 软件部署

```bash
# 1. 安装依赖
sudo apt-get update
sudo apt-get install cmake g++ python3.11 python3-pip

# 2. 编译设备桥
cd hardware_platform/bridges
# 编译 link2_bridge 和 x4air_bridge
```

## 8. 安全与约束

### 8.1 云台控制安全

#### 范围检查

```python
# Link 2 PTZ 范围（硬件限制）
PAN_MIN = -145.0   # 度
PAN_MAX = 145.0
TILT_MIN = -45.0
TILT_MAX = 90.0

# 所有命令在发送前必须验证范围
def validate_ptz(pan: float, tilt: float) -> bool:
    if not (PAN_MIN <= pan <= PAN_MAX):
        raise ValueError(f"Pan {pan}° out of range [{PAN_MIN}, {PAN_MAX}]")
    if not (TILT_MIN <= tilt <= TILT_MAX):
        raise ValueError(f"Tilt {tilt}° out of range [{TILT_MIN}, {TILT_MAX}]")
    return True
```

#### 速率限制

```cpp
// device_manager.cpp
class DeviceManager {
private:
    static constexpr int MAX_CMD_PER_SEC = 10;
    std::deque<std::chrono::steady_clock::time_point> command_timestamps_;

public:
    bool rate_limit_check() {
        auto now = std::chrono::steady_clock::now();
        
        // 清理 1 秒前的时间戳
        while (!command_timestamps_.empty()) {
            auto diff = std::chrono::duration_cast<std::chrono::seconds>(
                now - command_timestamps_.front()
            ).count();
            
            if (diff >= 1) {
                command_timestamps_.pop_front();
            } else {
                break;
            }
        }
        
        // 检查是否超过速率限制
        if (command_timestamps_.size() >= MAX_CMD_PER_SEC) {
            return false;  // 拒绝命令
        }
        
        command_timestamps_.push_back(now);
        return true;
    }
};
```

#### 超时保护

```cpp
// 所有命令都有 1 秒超时
void signal_handler(int signal) {
    if (signal == SIGINT || signal == SIGTERM) {
        g_running = false;
        
        // 安全退出：发送 PTZ Stop
        if (g_device_manager && g_device_manager->is_connected()) {
            std::cout << "[SAFETY] Sending PTZ Stop before exit\n";
            g_device_manager->ptz_stop();
        }
    }
}
```

### 8.2 录制控制安全

#### 禁止的操作

**不允许 LLM 或自动化脚本调用的命令**:
- 固件升级 (`firmware_update`)
- 恢复出厂设置 (`factory_reset`)
- 格式化存储卡 (`format_storage`)

这些命令仅通过手动 UI 或管理员权限调用。

#### 素材删除二次确认

```python
async def delete_file(self, file_path: str, confirm: bool = False):
    """删除文件需要二次确认"""
    if not confirm:
        raise ValueError("delete_file requires confirm=True")
    
    # 检查是否是关键素材
    if "important" in file_path.lower():
        raise ValueError("Cannot delete important files")
    
    # 执行删除
    result = await self.execute_command(DeviceCommand(
        command_id=f"del_{uuid.uuid4()}",
        action="delete_file",
        args={"file_path": file_path},
    ))
    
    return result
```

#### 隐私保护

**人脸/声音素材处理**:
1. 录制前必须取得被摄者授权
2. 上传云端前可选择模糊面部（本地检测 + 高斯模糊）
3. 删除素材时同步删除云端备份

```python
class EdgeAgent:
    async def _write_to_outbox(self, event: DeviceEvent):

    async def _cloud_sync_loop(self):
```
